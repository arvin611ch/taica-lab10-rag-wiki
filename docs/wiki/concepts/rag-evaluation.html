怎麼評估 RAG

一句話定義： 評估 RAG 要分開看「找回的資料好不好」和「答案好不好」，常用三個分數：資料相關性、答案忠實度、答案切題度。

白話解釋

分數 問的問題 評的是
資料相關性（context relevance） 找回來的資料精不精簡、有沒有一堆無關內容？ 檢索
忠實度（faithfulness） 答案的每一句，資料裡都找得到依據嗎？ 生成
答案切題度（answer relevance） 答案有沒有回應問題本身？ 生成

忠實度的算法很直觀：把答案拆成幾句短的敘述，逐句問「這句能從資料推出來嗎？」，能推出的句數除以總句數就是忠實度。

RAGAS 用 LLM 自動做這些判斷，所以不需要先請人寫好標準答案。但自動評估也會錯，尤其是資料相關性最難評。

來源怎麼說

  • 綜述論文列出三個品質分數。S3-c8
  • 忠實度：答案應該建立在找回來的資料上。S5-c1
  • 切題度與資料相關性的定義。S5-c2
  • 忠實度的算法是拆句後逐條驗證。S5-c3
  • 不需要人工標的標準答案。S5-c4
  • 跟人類判斷比，忠實度最準，資料相關性最難。S5-c5
