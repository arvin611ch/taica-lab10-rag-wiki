# 參數記憶與幻覺

**一句話定義：** 參數記憶（parametric memory）是語言模型在訓練時存進模型參數裡的知識；幻覺（hallucination）是模型寫出聽起來合理、但沒有根據或錯誤的內容。

## 白話解釋

語言模型讀過大量文字後，把其中的知識「壓縮」進數十億個參數。問它問題時，它是從這些參數「回想」答案。這有三個麻煩：

1. **難更新：** 世界變了（例如換了總統），模型不會知道，除非重新訓練。
2. **說不出依據：** 模型無法指出答案是從哪份資料學來的。
3. **會幻覺：** 記不清楚時，模型仍會流暢地寫出一個答案。

比喻：參數記憶像一個讀過很多書、但沒帶任何書的人。他能回答很多問題，卻無法翻書確認，也說不出是在哪本書看到的。
