RAG 入門 LLM Wiki：目錄

主題：檢索增強生成（RAG）。讀者：沒學過機器學習的大學生。7 篇原始資料，所有事實都附主張編號，可追到原文。規則見 AGENTS.md。

總覽

  • 總覽：RAG 是什麼、為什麼需要、會在哪裡出錯 — 7 篇來源串成的故事線，也是簡報骨架
  • 名詞表 — 16 個名詞的一句話定義，簡報檢查會用到

概念

  • 檢索增強生成（RAG） — 先找資料再回答；建索引、檢索、生成三步
  • 參數記憶與幻覺 — 為什麼只靠模型記憶不夠
  • 檢索器 — 關鍵字檢索與語意檢索兩大類
  • 向量嵌入 — 用數字表示意思，換句話說也找得到
  • 關鍵字檢索 BM25 — 比對字面，擅長代碼與專有名詞
  • 切塊 — 長文件切成小段；大小是取捨，會丟上下文
  • 混合檢索與重排 — 兩種檢索合併，再挑出最相關的
  • 長上下文的位置效應 — 放中間的資料容易被忽略
  • RAG 的常見失敗 — 找不到、沒用好、沒照資料寫
  • 怎麼評估 RAG — 資料相關性、忠實度、答案切題度
  • RAG 的三個階段 — Naive、Advanced、Modular
  • RAG 與微調 — 換資料 vs 改模型
  • LLM Wiki 與 RAG 的差別 — 臨時找 vs 事先整理
