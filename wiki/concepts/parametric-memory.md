# 參數記憶與幻覺

**一句話定義：** 參數記憶（parametric memory）是語言模型在訓練時存進模型參數裡的知識；幻覺（hallucination）是模型寫出聽起來合理、但沒有根據或錯誤的內容。

## 白話解釋

參數（parameter）是模型內部的大量數字；訓練就是讓模型讀大量文字、反覆調整這些數字。語言模型讀過大量文字後，等於把其中的知識「壓縮」進這些參數。問它問題時，它是從這些參數「回想」答案。這有三個麻煩（來源的語氣是「不容易」「可能」）：

1. **不易更新：** 世界變了（例如換了總統），模型不會知道，除非重新訓練。
2. **難說明依據：** 很難看出答案是從哪份資料學來的。
3. **可能幻覺：** 記不清楚時，模型仍可能流暢地寫出一個答案。

比喻：參數記憶像一個讀過很多書、但沒帶任何書的人。他能回答很多問題，卻無法翻書確認，也說不出是在哪本書看到的。

## 來源怎麼說

- 2020 年的 RAG 論文指出語言模型把知識存在參數裡，並列出這三個缺點（原文的語氣是「不容易」「可能」）。[S1-c1](../sources/s1-lewis-2020-rag.md#s1-c1)
- 綜述論文對大型語言模型提出同樣的問題：幻覺、知識過時、推理無法追溯。[S3-c1](../sources/s3-gao-2023-rag-survey.md#s3-c1)
- 外部的、可檢索的記憶可以直接修改，也能拿出來檢查。[S1-c2](../sources/s1-lewis-2020-rag.md#s1-c2)
